# Karen's Home Daycare

Static website for Karen's Home Daycare in Chelsea, Quebec. Hosted on GitHub Pages.

## Update contact details

Edit `config.js` (phone, email, Facebook link, ages, hours, openings). Any value left as `""` is hidden. Commit the change and the site updates within a minute or two.

## Pages

- `index.html` Home
- `about.html` About
- `programs.html` Programs and Hours
- `contact.html` Contact
