# Karen's Home Daycare

Static website for Karen's Home Daycare in Chelsea, Quebec. Hosted on GitHub Pages.

## Update contact details

Edit `config.js` (phone, email, Facebook link, ages, hours, openings). Any value left as `""` is hidden everywhere it appears (Contact page, Programs table, footer). Commit the change and the site updates within a minute or two.

## Pages

- `index.html` Home
- `about.html` About
- `programs.html` Programs and Hours
- `guide.html` Parent Guide (hub)
  - `choosing.html` How to choose a daycare: questions to ask
  - `space.html` What makes a good daycare space?
- `contact.html` Contact

The guide pages are general parent information and make no claims about Karen's licensing, recognition, or capacity. Do not add such claims until they are confirmed.
